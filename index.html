What v0.1 actually includes

The workplace, without the marketing fog.

GlassGraph Studio v0.1 is one product and one local workplace. These are its current user-facing boundaries.

01

Packs

Packs are the starting point for opening organized board material in the workplace.

02

Four workplace views

Index, Runbook, Matrix, and Copilot are the current views inside the same GlassGraph workplace.

03

Local autosave

The active board is saved locally while you work. Autosave is not presented as an exported file.

04

Explicit board export

A .board.json file is created only when you explicitly export it. It uses board schema v6.

Connections and privacy

Nothing connects by implication.

The app stays local by default. Network and AI boundaries are stated plainly so you know what leaves the workplace and when.

M

Explicit MCP session

When you deliberately start an explicit MCP session, the connected host can receive the full active board. v0.1 does not claim that it shares only a smaller previewed subset.

0

No telemetry

GlassGraph Studio sends no product analytics or usage telemetry.

↑

Updates are conditional

The updater checks GitHub for GlassGraph release information when enabled. The update path is still completing release acceptance.

Copilot boundary: Copilot is a workplace view in v0.1. That does not mean built-in AI execution is active.
