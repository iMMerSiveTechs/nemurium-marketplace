About NEMURIUM

One home for products that make complex work easier to see.

NEMURIUM is the independent product brand behind GlassGraph Studio. It is where connected-work tools are developed and explained in one place.

GlassGraph Studio is NEMURIUM’s first public product. The focus now is finishing and supporting this workplace before introducing anything else.

What GlassGraph includes

See connected work without losing the bigger picture.

GlassGraph Studio v0.1 brings your board, its structure, and four ways to explore it into one local workplace.

01

Packs

Packs are the starting point for opening organized board material in the workplace.

02

Four workplace views

Index, Runbook, Matrix, and Copilot are the current views inside the same GlassGraph workplace.

03

Local autosave

The active board is saved locally while you work. Autosave is not presented as an exported file.

04

Explicit board export

A .board.json file is created only when you explicitly export it. It uses board schema v6.

Connections and privacy

Connections are optional and user-started.

The app stays local by default. You decide when to connect another tool, and the app explains what that connection can access.

M

Optional tool connection

MCP is an optional connection method. When you deliberately start an explicit MCP session, the connected tool can receive the full active board. Nothing connects automatically.

0

No telemetry

GlassGraph Studio sends no product analytics or usage telemetry.
