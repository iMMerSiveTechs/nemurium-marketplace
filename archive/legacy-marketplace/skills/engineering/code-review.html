SKILL

Code Review

Transform code review from checkbox exercise to intelligent quality assurance. Automatically detect security vulnerabilities, performance bottlenecks, and correctness issues while providing mentoring feedback that strengthens team capabilities.

Core Capabilities

🔐

Security Analysis

Identify SQL injection risks, authentication bypasses, exposed secrets, unsafe serialization, and credential leaks. Flag OWASP Top 10 vulnerabilities before they reach production.

⚡

Performance Review

Spot N+1 queries, memory leaks, inefficient algorithms, and blocking operations. Provide optimization suggestions with concrete impact estimates and refactoring approaches.

✅

Correctness Validation

Check for race conditions, off-by-one errors, null pointer handling, and logic flaws. Verify test coverage for critical paths and suggest edge cases that might be missed.

📖

Best Practice Guidance

Reference architectural patterns, framework conventions, and team standards. Surface violations of established practices with context and corrective examples.

🎓

Mentoring-Focused Feedback

Explain not just what's wrong, but why and how to improve. Includes learning resources, explains design tradeoffs, and helps junior developers grow from each review.

🔄

Context-Aware Analysis

Understand surrounding code, related files, and business context. Make recommendations that fit your specific architecture, not generic lint rules.

Real-World Applications

🚀 Accelerating Throughput

Review velocity increases dramatically. Automated checks handle routine issues, freeing reviewers to focus on architecture, design patterns, and business logic. Cut review time by 40% while improving quality.

🛡️ Pre-incident Security

Catch authentication bugs, data exposure, and injection vectors before they become security incidents. Compliance-focused teams gain confidence in deployment with documented security review.

📈 Growing Teams

Inconsistent code quality as team scales? Automated reviews establish consistent standards, catch junior developer mistakes early, and accelerate learning through detailed feedback.

🎯 Reducing Hotfixes

Catch edge cases, off-by-one errors, and race conditions before release. Reduced post-deployment defects means fewer firefighting sessions and more time on features.
